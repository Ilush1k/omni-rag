# Соответствие отчёта текущему коду

Включены исходные материалы практики: [отчёт Word](practice-report.docx) и [презентация](project-presentation.pptx). Они описывают общую задачу, сценарии, модель данных и демонстрацию командного проекта. Ниже отделены подтверждённые компоненты от описаний, которые нельзя воспринимать как проверенную функциональность этой версии.

| Материал | Что есть в коде |
|---|---|
| Парсинг документов, Qdrant и гибридный поиск | Реализованы в `src/indexing/` и `src/frontend/app.py` |
| Обход графа BFS | Реализован в `src/graph/traversal.py`, ограничены глубина и число дополнительных узлов |
| Cross-Encoder и Top-4 | Реализованы в `src/core/rag.py` |
| Память Redis/PostgreSQL и summary | Реализованы в `src/memory/` и подключены к Streamlit |
| FastAPI, маршруты `/api/search`, `/api/chat`, SSE API | В этой ветке отдельного FastAPI-сервера нет; интерфейс вызывает Python-модули напрямую и показывает поток ответа Streamlit |
| Асинхронная фоновая суммаризация | В текущем UI вызов последовательный после генерации ответа |
| Чанкинг по 1000 токенов | Индексатор использует RecursiveCharacterTextSplitter с размерами в символах; параметры временных файлов отличаются |
| Авторизация по ID | ID выбирает память; проверки личности и разграничения доступа нет |
| Сокращение нерелевантного шума более чем на 70% | Выбор Top-4 из большего числа кандидатов сам по себе не измеряет качество поиска; воспроизводимая оценка не приложена |
| 100% конфиденциальность и отсутствие галлюцинаций | Локальный инференс и промпт снижают некоторые риски, но не доказывают абсолютные гарантии |

Для портфолио используйте описание реализованных функций из README. Исторические учебные документы сохранены без скрытого переписывания; таблица выше уточняет их связь с исходниками.
