# Проверка публикации

Проверено 3 ноября 2026 года. Основа — исходная ветка `feature/rag-memory-graph`, коммит `a2c3c3295e04725dd010be40c3f27481f08759ea`.

- Локальный запуск тестов на Python 3.12: **12 passed, 1 skipped**. Интеграционный тест пропущен без специально заданных тестовых подключений.
- Изолированный Docker-запуск на Python 3.11 с Redis 7 и PostgreSQL 16: **13 passed**. Проверено сохранение summary в обеих системах, завершение горячего сеанса, восстановление архива в новом сеансе и разделение пользователей.
- Qdrant проверен через настоящий in-memory клиент: глубина BFS, ограничение числа соседей и циклические связи. Отказ клиента дополнительно проверен тестовым объектом.
- Проверены обработка отказа PostgreSQL, TTL горячей памяти, сохранение предыдущего summary при пустом ответе и ограничение размера summary. LLM заменена тестовым объектом.
- Docker Compose успешно объединяет основной файл и `compose.ollama.yml` для CPU-профиля; приложение получает адрес `http://ollama:11434`.
- Проверены синтаксис Python, локальные ссылки Markdown и наличие исходных документов. Отчёт и презентация перенесены без изменения содержимого.

После проверки удалены контейнеры и сеть только отдельного тестового Compose-проекта. Рабочие документы, приватные настройки и история диалогов в проверке не использовались.

Полная сборка основного образа с нейросетевыми зависимостями, загрузка моделей, индексация документов, генерация ответа и GPU-запуск не выполнялись. Тесты подтверждают перечисленные свойства графа и памяти, но не измеряют качество retrieval или ответов LLM. Основной `requirements.txt` сохраняет незакреплённые версии исходного проекта; воспроизводимая фиксация полного окружения требует отдельного прогона.
